# Sprint 6 — Evals and Alpha Polish

## Goal

Ship a credible alpha with eval evidence and strong UX.

## Deliverables

- eval task set,
- eval runner,
- JSON/markdown eval report,
- improved CLI output,
- alpha release checklist,
- docs pass.

## Stories

### S6-1 Eval harness

Acceptance:

- Runs at least 10 fixed tasks.
- Records route, cost, success, tests, review status.

### S6-2 Cost dashboard report

Acceptance:

- Shows cost per route and role.
- Shows Opus activation rate.

### S6-3 Alpha release checklist

Acceptance:

- Install docs tested.
- Config docs complete.
- Known limitations documented.

## Alpha exit criteria

- Normal code change route works end to end.
- Security-sensitive route works with blocking review.
- Budget hard cap proven.
- No shell/network/git push bypass found in manual testing.
