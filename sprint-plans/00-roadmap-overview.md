# Manta CLI v1 Roadmap Overview

Assumption: 2-week sprints. Adjust durations based on team size.

## Sprint sequence

| Sprint | Theme | Outcome |
|---|---|---|
| Sprint 0 | Repo bootstrap | Docs, scaffold, CI, standards |
| Sprint 1 | Core CLI foundation | `init`, `route`, `run --dry-run`, sessions |
| Sprint 2 | Budget router | cheap router, route mapping, ledger |
| Sprint 3 | Deep Agents runtime | builder/reviewer model-backed loop |
| Sprint 4 | Context broker | repo map, file selection, manifests |
| Sprint 5 | Review/security gates | test loop, code review, security review, policy |
| Sprint 6 | Evals and alpha polish | eval harness, UX polish, alpha release |

## Definition of ready

A story is ready when it has:

- user value,
- inputs/outputs,
- acceptance criteria,
- security impact,
- budget/cost impact,
- test plan.

## Definition of done

A story is done when:

- code merged,
- tests pass,
- docs updated,
- config/schema updated if needed,
- security implications addressed,
- demo command works.
