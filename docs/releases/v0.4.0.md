# Manta v0.4.0

Manta now provides a visible agent team on dependable harness foundations.
Create and configure specialists in `/agents`, assign work through `/tasks`
(or `/team`), answer saved input and approval requests, and inspect observed
tests, artifacts, spend and the exact diff before integrating isolated changes.

The Databricks `/model` picker now lists the active workspace's discovered Unity
Gateway services and legacy chat endpoints without unrelated direct-key provider
rows. The Manta ray, wordmark, version and title are restored in the welcome
screen, including narrow and ASCII terminals.

## Dependable foundations

- Required runtime composition, policy, accounting and checkpoint adapters fail
  closed with a diagnosis. Direct, delegated and JavaScript tool dispatch share
  policy, approval and audit paths.
- Agent memory uses its compiled namespace. Generated `MANTA_ROLE.md` is separate
  from learned `AGENTS.md` context; profile sync preserves learned content, and
  migrations back up old files and SQLite notes.
- Exact model-service/protocol evidence drives effort choices, model cards and
  context/output preflight. Unknown capabilities stay explicit.
- Main, specialist and helper requests share a deduplicated usage ledger with
  reported reasoning/cache usage, purpose and latency. Budgets checkpoint between
  requests and support durable explicit continuation. Unknown usage/prices remain
  visible.
- `manta doctor` separates required adapter health from compiled graph validation.
  `manta runtime` exposes inherited commands and help. The Manta-owned updater
  installs a complete tagged release with matching dependency constraints.

## Visible agent team

- `/agents`, the CLI and SDK share agent creation, cloning, editing, persistent
  enable/disable, validation, typed effort/output controls and task assignment.
  Definitions reload safely while the runtime is idle.
- `/tasks` and `/team` show inline and detached work, hierarchy, dependencies,
  progress, logs, steering and exact pending input/approval decisions.
- Detached tasks use owned Git worktrees or directory snapshots. Input, tool
  approvals and budgets resume the saved task/thread across runner/server
  restarts. Durable scheduling bounds concurrency and reconciles queued work.
- Review shows complete diffs, observed test exit codes, attached artifacts and
  cost completeness. Integration checks the exact reviewed patch and conflicts,
  preserving unrelated caller edits and the Git index. Discard retains receipts.

## Install or upgrade

Python **3.12 or newer** is required. The qualified runtime remains Deep Agents
Code **0.1.86** and Deep Agents **0.7.28**, using LangChain OpenAI with Databricks
SDK authentication. Use the release's `requirements-dev.lock`; runtime and
supporting dependencies are qualified together.

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) and Git,
then run in Bash:

```bash
uv python install 3.12
uv tool install --force --upgrade --python 3.12 \
  --constraints https://raw.githubusercontent.com/althrussell/manta-code/v0.4.0/requirements-dev.lock \
  "manta-code[agent] @ git+https://github.com/althrussell/manta-code.git@v0.4.0"
uv tool update-shell
manta --version
manta -p my-workspace doctor
```

`manta --version` should print `0.4.0`. Existing user model pins, configuration,
registry, usage ledger and saved sessions are preserved. Inspect project config
and agent pins if you want to adopt different models.

**v0.3.0 and earlier do not have the Manta-owned updater**; use the explicit
installation above. A tag-pinned `uv tool upgrade` stays on its original tag.
After installing v0.4.0, `manta update --check` checks newer stable releases and
`manta update --version <stable-tag>` installs the selected complete release.
Exit active sessions before updating. Editable checkouts retain deliberate
Git/lockfile updates.

The release includes a wheel, source archive, dependency constraints, these notes
and `SHA256SUMS`. Verify checksums before installing downloaded assets. Full uv,
pip, Windows, authentication and migration instructions are in the
[installation guide](https://github.com/althrussell/manta-code/blob/v0.4.0/docs/16-installation-and-upgrades.md).

## Qualification and limits

The reviewed combined source passed **1,126 tests on Python 3.12.8** and
**1,126 tests on Python 3.14.5**, plus Ruff, dependency consistency and source/wheel
integrity checks. An installed wheel passed **41 mounted CLI/SDK/integration
checks outside the checkout**. GitHub CI passed on the merged source; independent
reviews found no remaining blockers.

Live labs qualification on `databricks:system.ai.gpt-6-1-sol` passed agent
creation/sync/dispatch, isolated work, separate input and write-approval restarts,
same-task/thread continuation, real passing pytest evidence, an artifact, exact
reviewed integration, a held acceptance test, caller-change preservation and
persistent disable. Four baseline repository fixtures also passed executable
acceptance. See the
[foundation record](https://github.com/althrussell/manta-code/blob/v0.4.0/docs/19-dependable-foundations.md)
and [team qualification](https://github.com/althrussell/manta-code/blob/v0.4.0/docs/qualification/visible-agent-team-2026-10-21.json).

Operational boundaries:

- Inline agents share the parent checkout. Detached Git tasks start from
  committed HEAD; staged, unstaged and untracked source edits are recorded but
  are not copied into the task.
- Detached shell execution is disabled by default. Configure each agent's
  `task_shell_allow_list` for its test commands. Worktrees and harness controls
  do not provide an operating-system sandbox.
- Integration applies files without committing. Integrated worktrees are retained
  for inspection; post-integration cleanup has no dedicated command. Submodule,
  symlink and non-Git file/directory structural changes need manual integration.
- Budgets are checked between requests. Unknown charges and one request's
  overshoot prevent a hard dollar ceiling; Gateway billing remains authoritative.
- Agent memory namespaces are not automatic project scope. Legacy unassigned
  notes stay inspectable and are excluded from automatic recall.
- Workspace permissions and exact model/protocol qualification still apply.
  Qualified Gemini targets use unified Chat. Claude Sonnet Responses rejects
  forced tool choice; use a qualified GPT helper for ToolStrategy rubric/goal
  checks. See the [model capability report](https://github.com/althrussell/manta-code/blob/v0.4.0/docs/18-model-capability-qualification.md).

**Measured model efficiency remains the next milestone.** Searchable, editable
and forgettable scoped memory, broader media/schema qualification, and comparative
model quality, latency and cost evaluations are pending. This release makes no
claim of model superiority or measured savings.
