# Manta v0.3.0

Manta now supports Unity AI Gateway model services such as
`system.ai.gpt-6-1-sol`, alongside existing Databricks serving endpoints. Model
discovery, inference, delegated agents, saved sessions, diagnostics, and usage
accounting share the same target selection and workspace authentication.

## Runtime and dependency migration

- Python 3.12 or newer is required; Python 3.12 and 3.14 are qualified in CI.
- Deep Agents Code 0.1.86 and Deep Agents 0.7.28 replace the previous runtime.
- Databricks-LangChain is replaced by LangChain OpenAI 1.7.2, OpenAI 3.31.0,
  and Databricks SDK 0.154.0. This resolves the MCP 1/MCP 2 dependency conflict.
- The complete qualified dependency graph is provided in `requirements-dev.lock`.
  Runtime compatibility pins are deliberate; dependency updates are tested together.

## Unity Gateway support

- Unity service names retain their full catalog and schema path. Explicit model
  selections work even when metadata discovery is unavailable to the caller.
- Unified Chat and Responses requests use refreshing Databricks unified auth.
  Streaming, tool continuations, structured output, multimodal messages, usage,
  reasoning state, and refusals are covered by protocol regression fixtures.
- Capability selection and saved protocol state are scoped to the selected model,
  workspace, and profile. Switching incompatible opaque history requires a fresh
  session. Delegated agents retain isolated histories and correct model provenance.
- Fresh role defaults use `system.ai.gpt-6-luna`, `system.ai.claude-opus-5-5`,
  `system.ai.gpt-6-1-sol`, and `system.ai.claude-sonnet-5-5`. Existing user-owned
  defaults and registry pins retain their configured values.
- `manta doctor` performs bounded metadata checks without inference. Optional
  `manta doctor --probe` qualifies tool loops and incurs model charges.
- Local cost reports preserve unknown service prices instead of inventing rates.
  Headless JSON and streaming JSON retain Manta's documented result envelopes.

The exact Gemini services qualified for this release prefer unified Chat because
Responses tool continuation currently fails in the gateway. Model availability,
metadata visibility, and inference permission depend on the workspace and caller.
See the [qualification report](https://github.com/althrussell/manta-code/blob/v0.3.0/docs/15-unity-gateway-qualification.md)
for the tested services and remaining limits.

## Install or upgrade

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) and Git,
then run in Bash:

```bash
uv python install 3.12
uv tool install --force --upgrade --python 3.12 \
  --constraints https://raw.githubusercontent.com/althrussell/manta-code/v0.3.0/requirements-dev.lock \
  "manta-code[agent] @ git+https://github.com/althrussell/manta-code.git@v0.3.0"
uv tool update-shell
manta --version
```

`manta --version` prints `0.3.0` without loading credentials or starting the agent.
The explicit new tag is necessary when upgrading a tool installed from an older
tag; `uv tool upgrade manta-code` retains that original source tag. Use a fresh
Python 3.12+ environment for pip installations to avoid retaining the older MCP 1
bridge dependencies.

The release includes a wheel, source archive, dependency lock, these notes, and
`SHA256SUMS`. Verify the checksums before installation. Full Git, wheel, pip,
authentication, and migration instructions are in the
[installation guide](https://github.com/althrussell/manta-code/blob/v0.3.0/docs/16-installation-and-upgrades.md).
