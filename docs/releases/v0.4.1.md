# Manta v0.4.1

Gemini 4 Argon now accepts Manta's complete coding-tool schema. In v0.4.0,
selecting Argon could fail before answering with
`OpenAIInvalidRequestError: An internal error occurred`: the Gateway rejected
`exclusiveMinimum` on the built-in `grep` tool's optional positive `max_count`
argument.

For the exact qualified Chat targets, Manta converts exclusive integer bounds
to equivalent inclusive bounds in outgoing schemas (`max_count > 0` becomes
`minimum: 1`). Original tool definitions and local validation remain unchanged.
Non-integer bounds retain their strict constraint in the description and use
the inclusive boundary; raw schema-only tools must validate their arguments.

Streamed tool signatures are also preserved when they arrive after the call ID,
in a signature-only fragment, or repeatedly. State stays local to each stream,
survives checkpoint serialization and is replayed with its original tool call.

The legacy endpoint `databricks-gemini-4-argon` is separately qualified from the
Unity service `system.ai.gemini-4-argon`. Both use their qualified Chat route
with streaming usage options and configurable reasoning effort disabled because
the Gateway rejects those controls. This evidence does not apply to the separate
`system.ai.databricks-gemini-4-argon` name, Responses, native Gemini APIs or
media inputs.

This patch retains v0.4.0's dependable foundations, visible agent team, Gateway
model picker, Manta branding and owned updater. Dependencies are unchanged:
Python **3.12+**, Deep Agents Code **0.1.86** and Deep Agents **0.7.28**, using
LangChain OpenAI with Databricks SDK authentication.

## Install or upgrade

Save your work and exit active Manta sessions. If v0.4.0 is already installed as
a uv tool or pip package, use the Manta-owned updater after v0.4.1 is published:

```bash
manta update --check
manta update --version v0.4.1
manta --version
manta -p my-workspace doctor
```

For a new install or a pre-v0.4.0 installation, install
[uv](https://docs.astral.sh/uv/getting-started/installation/) and Git, then run:

```bash
uv python install 3.12
uv tool install --force --upgrade --python 3.12 \
  --constraints https://raw.githubusercontent.com/althrussell/manta-code/v0.4.1/requirements-dev.lock \
  "manta-code[agent] @ git+https://github.com/althrussell/manta-code.git@v0.4.1"
uv tool update-shell
manta --version
```

The version should print `0.4.1`. Start a fresh `manta` process after installing.
Existing configuration, model pins, registry, usage ledger and saved sessions
are preserved. Editable checkouts require deliberate Git/lockfile updates.

The GitHub release includes a wheel, source archive, dependency constraints,
these notes and `SHA256SUMS`. Verify checksums before installing downloaded
assets. Full uv, pip, Windows and authentication instructions are in the
[installation guide](https://github.com/althrussell/manta-code/blob/v0.4.1/docs/16-installation-and-upgrades.md).

## Qualification

The Argon fix passed **1,155 tests on Python 3.12 and Python 3.14**, with green
GitHub CI and independent review. The reporting user confirmed the fix works.
Live `labs` checks passed unary and streaming tool roundtrips for both exact
targets, including checkpoint serialization and signed continuation.

Both targets also passed the actual asynchronous interactive harness with all
**34 tools**, memory enabled, validated runtime controls and manual approvals.
Each executed a real `grep` with `max_count=1`, returned the expected fixture
token and left the fixture unchanged. A separate fresh-conversation Unity
service run passed the same graph, matching the reported failure. Tests used
disposable projects and state directories. See the
[Argon qualification record](https://github.com/althrussell/manta-code/blob/v0.4.1/docs/21-gemini-argon-harness-qualification.md)
for exact evidence and scope.

Workspace permissions and exact model/protocol qualification still apply.
The [v0.4.0 operational boundaries](https://github.com/althrussell/manta-code/blob/v0.4.1/docs/releases/v0.4.0.md#qualification-and-limits)
remain applicable. Measured model efficiency remains the next milestone;
this patch makes no comparative quality, latency or savings claim.
