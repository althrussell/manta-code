# repo-map

## Purpose

Create a compact, token-efficient summary of the repository.

## Instructions

1. List top-level directories.
2. Identify package/config files.
3. Identify source and test directories.
4. Exclude dependency/build folders.
5. Summarize likely app entrypoints.
6. Return a concise map suitable for planner context.
