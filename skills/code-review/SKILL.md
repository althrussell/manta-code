# code-review

## Instructions

1. Read the acceptance criteria.
2. Review the diff first.
3. Inspect surrounding code only when necessary.
4. Identify material issues.
5. Classify severity.
6. Return structured required fixes.
7. Approve only if findings are non-blocking or absent.
